# Chat com WebSocket (v3)

##🚀 Sobre o Projeto
Este é um projeto de um chat em tempo real desenvolvido para demonstrar a comunicação full-duplex entre clientes e um servidor utilizando a tecnologia WebSocket. A aplicação permite que múltiplos usuários se conectem e troquem mensagens instantaneamente, sem a necessidade de recarregar a página.

Este projeto foi criado como uma forma de aplicar e aprofundar os conhecimentos em desenvolvimento web, especialmente no que tange à comunicação em tempo real e à interação dinâmica no lado do cliente.

## 🚀 Funcionalidades

- Conexão persistente via WebSocket
- Envio e recebimento de mensagens em tempo real
- Lista de contatos + várias salas de chat
- Indicador de status de conexão
- Reconexão automática ao cair a conexão

## 🧩 Tecnologias

- **Servidor**: `ws` (Node.js WebSocket server)
- **Cliente**: Vanilla JS + HTML/CSS
- Gerenciamento de eventos: open, message, close, error
